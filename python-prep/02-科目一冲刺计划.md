# 阶段 C：科目一冲刺计划（约 3～4 周）

前置：阶段 A 完成；模块 2～5 大部分做过；能独立写中等偏易题。

## 整体结构

| 周次 | 重点 | 模考 |
|------|------|------|
| 冲刺第 1 周 | 数组/字符串/哈希/双指针/栈队列/贪心 | 周末 1 场 |
| 冲刺第 2 周 | DFS/BFS/回溯 + 二叉树 + 二分/堆 | 周末 1 场 |
| 冲刺第 3 周 | DP + 图（困难主力） | 周末 1 场（2中+1难） |
| 冲刺第 4 周 | 全真模考 + 错题 + 模板 | 隔天 1 场，共 3～4 场 |

## 冲刺第 1 周：主干手速

每天 1.5～2h，**中等题为主**。

| 天 | 专题 | 题量参考 |
|----|------|----------|
| 1–2 | 数组 / 字符串 / 模拟 | 6～8 |
| 3–4 | 哈希 / 双指针 / 滑动窗口 | 6～8 |
| 5–6 | 栈队列 / 排序 / 贪心 | 6～8 |
| 7 | **限时模考 3 题** + 复盘 | 1 场 |

练习法：读题 → 写完整程序 → 自测边界；单题想超 35 分钟仍无思路 → 看题解 → **合上默写**。

## 冲刺第 2 周：搜索与树

| 天 | 专题 |
|----|------|
| 1–2 | DFS / BFS / 回溯（剪枝） |
| 3–4 | 二叉树（遍历、路径、LCA、层序） |
| 5–6 | 二分 / 优先队列 |
| 7 | **限时模考 3 题** |

本周起强制：断网手敲或关闭自动补全。

## 冲刺第 3 周：DP 与图

| 天 | 专题 |
|----|------|
| 1–2 | 线性 DP、背包、路径 DP |
| 3–4 | 区间 DP / 状压（选做，够用即可） |
| 5–6 | 图：拓扑、最短路、连通块 |
| 7 | **限时模考（刻意 2 中 + 1 难）** |

困难题策略：先写对能拿分的版本，再优化。

## 冲刺第 4 周：模考周

- 隔天 1 场「2 中 + 1 难」全真模拟（共 3～4 场）  
- 非模考日：只刷**错题 + 模板默写**，不追新题  
- 考前 2 天：只看模板本和错题本，早睡  

## 刷题平台建议

- LeetCode（中等题库为主）  
- 也可沿用公司/培训提供的机考模拟环境（优先贴近真实考场）

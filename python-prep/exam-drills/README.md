# 科目一题型训练（按上次考试画像）

下次不会出原题，但题型高度相似。按下面三类练即可。

| 类型 | 对应上次 | 训练重点 |
|------|----------|----------|
| A 类模拟 | 日志系统 | `__init__` 状态、列表/字典、边界规则 |
| B 数组窗口 | 代码密集度 | 分段、定长滑动窗口 |
| C 指令/状态机 | 指令执行 | 十六进制解析、寄存器/栈/顺序执行 |

**28 天用法建议**
- 第 1 周：A1 + B1（先建立手感）
- 第 2 周：A2 + B2 + 中等哈希/双指针
- 第 3 周：C1（简化版虚拟机）+ 搜索入门
- 第 4 周：A3/B3 限时模考 + 复盘

每题要求：自己先写；卡 40 分钟再看题解思路；合上重写到能跑通样例。

答案与要点见同目录 `题型训练-参考答案.md`（先别看）。

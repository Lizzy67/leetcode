## B2 最长活力区间（难度：中）

`scores[i]` 为每天得分，`0` 表示休息日（打断连续）。

给定 `k`：在任意一段连续非休息日中，选长度恰好为 `k` 的子段，使其得分和最大。  
若所有连续非休息段长度都 `< k`，则用 `k = 最长连续非休息天数` 再算。

返回最大和；若没有任何非休息日，返回 `0`。

### 样例
```text
scores = [3, 1, 0, 5, 5, 5, 0, 2], k = 3
最长非休息 = 3，k 保持 3
第二段 5+5+5 = 15 -> 15

scores = [2, 2, 0, 4], k = 3
最长非休息 = 2 < 3，k 改为 2
第一段 2+2=4，第二段只有 4（长度1不足）-> 4
```

## B3 至少含 1 个优质商品的最短子数组（难度：中）

`prices[i]` 商品价格；`good[i] == 1` 表示优质，`0` 表示普通。

求最短连续子数组长度，使其中优质商品个数 `>= need`。  
若不存在，返回 `-1`。

（可变长滑动窗口，和 B1 不同，但同属窗口家族。）

### 样例
```text
prices 可忽略，只用 good：
good = [0,1,0,1,1,0], need = 2 -> 2   # 下标3~4
good = [0,0,0], need = 1 -> -1
```

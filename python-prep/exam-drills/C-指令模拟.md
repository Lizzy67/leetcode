## C1 迷你机（难度：中上 → 难，必练）

### 机器状态
- 寄存器 `R0..R7`，初值 0（先只做 8 个，降低复杂度）
- 内存 `mem`：长度为 `n` 的整数列表，由输入给出
- 栈 `stack`：空列表
- `pc`：当前指令下标，从 0 开始

### 指令格式
每条指令是 **6 位十六进制字符串**（3 字节），解码如下：

```text
字节0（前2个hex）：opcode
字节1（中2个hex）：reg（寄存器编号 0~7）
字节2（后2个hex）：imm（立即数 0~255）
```

例：`"01030A"` → opcode=0x01, reg=3, imm=10

### 指令表

| opcode | 名称 | 含义 |
|--------|------|------|
| 0x01 | LOAD | `R[reg] = mem[imm]`（imm 越界则忽略，pc+1） |
| 0x02 | STORE | `mem[imm] = R[reg]`（imm 越界则忽略，pc+1） |
| 0x03 | ADD | `R[reg] = (R[reg] + imm) % 65536` |
| 0x04 | JMP | `pc = imm`（不自动 +1；imm 越界则停机） |
| 0x05 | PUSH | `stack.append(R[reg])` |
| 0x06 | POP | 栈非空则 `R[reg] = stack.pop()`，否则 `R[reg]=0` |
| 0x07 | HALT | 停机 |
| 其他 | NOP | `pc += 1` |

除 `JMP` / `HALT` 外，执行后 `pc += 1`。  
遇到 `HALT`、`pc` 越界、或执行步数超过 `10000`（防死循环）则停止。

### 函数签名
```python
def exec_mini(instructions: List[str], mem: List[int]) -> List[int]:
    """返回最终内存 mem"""
```

### 样例 1
```text
mem = [0, 0, 0, 0]
instructions = [
  "010000",  # R0 = mem[0] = 0
  "030005",  # R0 = 0+5 = 5
  "020002",  # mem[2] = 5
  "070000",  # HALT
]
输出: [0, 0, 5, 0]
```

### 样例 2
```text
mem = [10, 20, 0]
instructions = [
  "010000",  # R0 = 10
  "050000",  # push R0
  "010001",  # R0 = 20
  "060001",  # R1 = pop = 10
  "020102",  # mem[2] = R1 = 10
  "070000",
]
输出: [10, 20, 10]
```

### 样例 3（跳转）
```text
mem = [0]
instructions = [
  "030001",  # R0 += 1  -> 1
  "030001",  # R0 += 1  -> 2
  "040000",  # JMP 0    死循环倾向，但有步数上限
]
# 超过 10000 步停机；最终 mem 仍是 [0]（没写回内存）
输出: [0]
```

## C2 加练（可选）

在 C1 上增加：

- `0x08 CALL`：`stack.append(pc+1)`，然后 `pc = imm`
- `0x09 RET`：`pc = stack.pop()`；栈空则停机

自拟 1 个小样例验证即可。

## 训练目标

练完 C1 你应会：

1. `int(hex_str[i:i+2], 16)` 拆字节  
2. `while` + `pc` 取指执行  
3. 寄存器 / 内存 / 栈 三分状态  
4. 用步数上限防止死循环

# 加宽刷题清单（不只押上次三题）

题库每月会变，但**题型**相对稳定。近一周目标：覆盖 6 类常见考法，而不是刷完整个题库。

## 原则
- 每天 **1～2 题精做**（能默写模板），不贪多
- 每题：先自己写 → 对答案 → **合上重写**
- 旧三题类型仍练，但只占约 1/3 时间

## 六类必覆盖

| 类型 | 代表题（LeetCode 名可搜） | 你已有基础 |
|------|---------------------------|------------|
| 哈希 | 两数之和、字母异位词、存在重复元素 | 两数之和练过 |
| 滑动窗口 | 定长最大和、无重复最长子串、B1密集度 | B1 已过 |
| 双指针 | 盛最多水、移动零、三数之和（中） | 切片基础有 |
| 栈/字符串 | 有效括号、字符串解码 | split/join 练过 |
| 搜索 BFS | 岛屿数量、二叉树层序 | 待开 |
| 模拟/设计 | 重写 A3、停车场、简单计数器类 | A1～A3 有 |

选做：入门 DP（爬楼梯、最大子数组）、二分查找骨架。

## 近 7 天排期（可错后一天，别停）

| 天 | 必做 |
|----|------|
| 1 | 两数之和默写 + 字母异位词 |
| 2 | 无重复最长子串 + 再盲写 B1 |
| 3 | 盛最多水 或 移动零 + 有效括号 |
| 4 | 岛屿数量（BFS） |
| 5 | 类模拟：限时重写 A3 或自拟规则 |
| 6 | 爬楼梯 + 最大子数组和 |
| 7 | 限时套题 90min：哈希1 + 窗口1 + 模拟/搜索1 |

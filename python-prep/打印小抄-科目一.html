2. 列表 list

写法改原列表？返回
a.append(x)是None
a.extend(iterable)是None
a.insert(i,x)是None
a.pop() / pop(i)是元素
a.remove(x)是None（没有则报错）
del a[i]是语句无返回
a.sort()是None
sorted(a)否新列表
a.reverse()是None
a[::-1]否新列表
a.index(x) / count(x)否下标 / 次数

安全删：if x in a: a.remove(x)　·　拷贝：b=a[:] 不是 b=a

3. 集合 set / 字典 dict

  • set：add / remove(没有报错) / discard(没有不报错) / pop()任意弹出；不能 s[0]
  • list 用 append；set 用 add
  • x in d 查的是键（= in d.keys()）
  • d.get(k, 0)：没有返回默认值，不写入
  • d.setdefault(k, [])：没有则写入再返回
  • 计数：d[x]=d.get(x,0)+1
  • 往 list 值里加：d.setdefault(k, []).append(x)

4. 切片 / 字符串

  • 左闭右开；a[1:4] 含1不含4
  • 负下标：-1 最后，-2 倒数第二
  • 切片越界不报错 → 空或不越界部分
  • a[4:2] → []（正步长走不到）
  • 倒序下标：range(len(a)-1, -1, -1)
  • 列：用 [v[j] for v in rows]，不是 rows[:][j]
  • strip 去两头空白；split() 按空白切且丢空段 → ["ab","cd"]
  • join：" ".join(map(str, nums))；元素必须是 str
  • 字符串不可变，没有 append

5. 真假值 / 小坑

  • 假：0, "", [], {}, None, False
  • [0] 为真（非空列表）
  • 0 or 5 → 5；3 and 4 → 4（返回操作数）
  • tuple 不可变，不能 append
  • enumerate(a) → (下标, 元素)

定长窗口最大和

window = sum(a[:k]); best = window
for i in range(k, len(a)):
    window += a[i] - a[i-k]
    best = max(best, window)

可变长窗口（至少 need 个 1）

left = cnt = 0; ans = n+1
for right, g in enumerate(good):
    cnt += g
    while cnt >= need:
        ans = min(ans, right-left+1)
        cnt -= good[left]; left += 1
return -1 if ans==n+1 else ans

i, j = 0, n-1

    elif s < target: i += 1

二分（左闭右开示例）

lo, hi = 0, n
while lo < hi:

    if a[mid] < x: lo = mid+1
    else: hi = mid
# lo 为插入位置/第一个 >= x

BFS 网格骨架

from collections import deque
q = deque([(sx,sy)]); vis={(sx,sy)}
while q:
    x,y = q.popleft()
    for dx,dy in ((0,1),(0,-1),(1,0),(-1,0)):
        nx,ny=x+dx,y+dy
        if 合法 and (nx,ny) not in vis:
            vis.add((nx,ny)); q.append((nx,ny))

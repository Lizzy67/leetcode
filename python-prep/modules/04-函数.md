## 题 4.2 质数工具包

实现三个函数：

```python
def is_prime(n: int) -> bool: ...
def primes_upto(n: int) -> list[int]:
    """返回 2..n 中所有质数。"""
def nth_prime(k: int) -> int:
    """返回第 k 个质数（k 从 1 开始，2 是第 1 个）。"""
```

读入一个整数 `x`：

- 若 `x ≥ 2`，输出 `is_prime(x)` 的 `Yes`/`No`，再输出 `primes_upto(x)`  
- 否则读入的是 `k` 的场景：也可约定输入两行——按你文档写清即可  

**推荐输入格式（统一）：**

```
第一行：命令 prime / list / nth
第二行：参数 n 或 k
```

示例：

```
输入：
nth
6
输出：
13
```

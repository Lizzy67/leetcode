## 题 6.4 极简银行账户类

实现：

```python
class Account:
    def __init__(self, owner: str, balance: float = 0.0): ...
    def deposit(self, amount: float) -> None: ...
    def withdraw(self, amount: float) -> bool:
        """余额不足返回 False，否则扣款并返回 True。"""
    def __str__(self) -> str:
        """例如：Alice: 100.00"""
```

读入命令序列（每行一条），直到 `end`：

- `create 姓名 初始余额`
- `deposit 金额`
- `withdraw 金额`（失败打印 `failed`）
- `show` 打印 `__str__`

假设只有一个账户。

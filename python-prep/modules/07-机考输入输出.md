# 模块 7：机考输入输出专项

**目标**：科目一最容易无谓丢分的地方——读入格式。  
**建议用时**：穿插练习，冲刺期每天 10～15 分钟。  
**前置**：模块 1～3。

---

## 常见模板

### 1）一行多个整数

```python
a, b = map(int, input().split())
nums = list(map(int, input().split()))
```

### 2）先 n 再一行 n 个数

```python
n = int(input())
nums = list(map(int, input().split()))
```

### 3）n 行，每行一个数

```python
n = int(input())
nums = [int(input()) for _ in range(n)]
```

### 4）多组，直到 EOF

```python
import sys
for line in sys.stdin:
    line = line.strip()
    if not line:
        continue
    a, b = map(int, line.split())
    print(a + b)
```

### 5）多组，直到 0 0

```python
while True:
    a, b = map(int, input().split())
    if a == 0 and b == 0:
        break
    print(a + b)
```

## 题 7.1 A+B 百炼

按下列三种格式**各写一版**程序（可分成三个文件）：

**格式 A**：单组：一行 `a b`，输出 `a+b`  
**格式 B**：第一行 `t`，随后 `t` 行每行 `a b`  
**格式 C**：多组 `a b` 直到 EOF

## 题 7.2 矩阵读入

第一行：`m n`  
随后 `m` 行，每行 `n` 个整数。  
输出矩阵的转置（`n` 行 `m` 列）。

```
输入：
2 3
1 2 3
4 5 6
输出：
1 4
2 5
3 6
```

## 题 7.3 不定长行

若干行输入，每行个数不一定相同，全是整数。  
对每一行输出该行的总和；输入到 EOF 结束。

```
输入：
1 2 3
10
4 5
输出：
6
10
9
```

## 题 7.4 混合类型行

每行格式：`姓名 年龄 分数1 分数2 ...`（分数个数 ≥1）。  
对每行输出：`姓名 平均分`（平均分保留 1 位小数）。  
输入到 EOF。

```
输入：
Alice 20 90 80 70
Bob 21 100
输出：
Alice 80.0
Bob 100.0
```

---

## 题 7.5 快读习惯（选做）

当数据量可能较大时，练习：

```python
import sys
data = sys.stdin.read().split()
# 用下标指针取 token
```

用该方式重写：第一行 `n`，后面共 `n` 个整数（可能分布在多行），输出最大值。

## 易错清单（考前必看）

- [ ] `input()` 读入是 **str**，记得 `int()` / `split()`  
- [ ] 空行、行末空格：先 `strip()`  
- [ ] 多组 EOF 不要用 `while True: input()` 硬撑，优先 `sys.stdin`  
- [ ] 输出格式：空格分隔 vs 每行一个，严格按题面  
- [ ] 浮点：`f"{x:.1f}"` 或 `round` 按题目要求

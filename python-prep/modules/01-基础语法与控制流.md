# 模块 1：基础语法与控制流

**目标**：变量、类型、输入输出、分支、循环。  
**建议用时**：2～3 天。  
**完成后**：勾选 `progress.md`，进入模块 2。

---

## 做题约定

1. 手敲，少复制  
2. 每题至少自测 3 组数据  
3. 尽量用函数包一层（可选，但推荐）

---

## 题 1.1 温度换算

输入一个摄氏温度（整数或小数），输出华氏温度，保留 1 位小数。

公式：`F = C * 9 / 5 + 32`

```
输入：
25
输出：
77.0
```

**考点**：`input`、类型转换、`print` 格式化

---

## 题 1.2 奇偶与正负

读入一个整数 `n`：

| 条件 | 输出 |
|------|------|
| `n > 0` 且偶数 | `positive even` |
| `n > 0` 且奇数 | `positive odd` |
| `n < 0` 且偶数 | `negative even` |
| `n < 0` 且奇数 | `negative odd` |
| `n == 0` | `zero` |

```
输入：
-3
输出：
negative odd
```

**考点**：`if / elif / else`、取模

---

## 题 1.3 累加求和

读入正整数 `n`，输出 `1+2+...+n`。  
**分别用 `for` 和 `while` 各写一版。**

```
输入：
100
输出：
5050
```

**考点**：循环、累加器

---

## 题 1.4 阶乘

读入非负整数 `n`（`0 ≤ n ≤ 20`），输出 `n!`。约定 `0! = 1`。

```
输入：
5
输出：
120
```

**考点**：循环累乘、边界 `n=0`

---

## 题 1.5 打印乘法表

无需输入。打印九九乘法表：

```
1*1=1
1*2=2  2*2=4
1*3=3  2*3=6  3*3=9
...
```

对齐不强制，关系要正确。

**考点**：嵌套循环

---

## 题 1.6 猜数字

程序内设定答案（可写死，如 `42`）。用户反复输入：

- 太大 → `too big`
- 太小 → `too small`
- 相等 → `correct` 并结束

最后输出一共猜了多少次。

**考点**：`while True`、计数、`break`

---

## 题 1.7 质数判断

读入整数 `n`（`n ≥ 2`），判断是否质数，输出 `Yes` 或 `No`。

```
输入：
17
输出：
Yes
```

**考点**：循环、提前退出、开方优化（可选）

---

## 题 1.8 数字位数与反转

读入一个正整数（不含前导零），输出：

1. 位数  
2. 数字反转（`1200` → `21`，去掉前导零）

```
输入：
1200
输出：
4
21
```

**考点**：字符串或整除取模两种思路都建议练

## 题 3.1 词频统计

读入一行英文句子（单词以空格分隔，先不考虑标点），输出每个单词出现次数。  
按单词**字典序**输出：`单词 次数`。

```
输入：
to be or not to be
输出：
be 2
not 1
or 1
to 2
```

## 题 3.2 两数之和（返回下标）

第一行：`n target`  
第二行：`n` 个整数  

找到两个下标 `i < j`，使 `a[i] + a[j] == target`。假设恰有一组解。输出 `i j`（从 0 开始）。

要求：尽量做到接近 O(n)（字典存「值 → 下标」）。

```
输入：
4 9
2 7 11 15
输出：
0 1
```

## 题 3.3 集合运算

第一行：集合 A 的元素  
第二行：集合 B 的元素  

输出三行（元素升序、空格分隔）：

1. 交集  
2. 并集  
3. 仅在 A 不在 B  

```
输入：
1 2 3 4
3 4 5 6
输出：
3 4
1 2 3 4 5 6
1 2
```

## 题 3.4 元组排序

读入 `n`，再读 `n` 行，每行：`姓名 分数`（分数为整数）。  
按分数**降序**排序；分数相同按姓名**升序**。输出排序后的姓名，每行一个。

```
输入：
3
bob 90
alice 90
carol 85
输出：
alice
bob
carol
```

提示：`sorted(list, key=lambda x: (-x[1], x[0]))`

```
输入：
abaccdeff
```

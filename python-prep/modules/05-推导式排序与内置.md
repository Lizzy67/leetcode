# 模块 5：推导式、排序与常用内置

**目标**：写得更短更稳；掌握 `sorted`、`enumerate`、`zip`、推导式。  
**建议用时**：1～2 天。  
**前置**：模块 2～4。

---

## 概念速记

```python
[x * x for x in range(5) if x % 2 == 0]
{c: s.count(c) for c in set(s)}   # 小数据可以；大数据用循环计数
{x for x in a}                    # 集合推导

for i, x in enumerate(a):
    ...
for x, y in zip(a, b):
    ...

sorted(a, reverse=True)
sorted(a, key=lambda x: x[1])
```

## 题 5.1 只用推导式

读入一行整数，用**列表推导式**完成并输出：

1. 所有偶数  
2. 所有数的平方  
3. 所有正数（`>0`）  

每项一行，元素空格分隔；若为空行则输出空行。

```
输入：
-2 3 4 0 5
输出：
-2 4
4 9 16 0 25
3 4 5
```

## 题 5.2 成绩分级

读入 `n`，再读 `n` 个分数（0～100）。  
用推导式生成等级列表：`≥90 A`，`≥80 B`，`≥70 C`，`≥60 D`，否则 `F`。  
输出等级，空格分隔。

```
输入：
5
95 82 73 60 59
输出：
A B C D F
```

## 题 5.3 多关键字排序

读入 `n` 个产品：每行 `名称 价格 销量`。  
排序规则：销量降序 → 价格升序 → 名称升序。  
输出排序后的名称，每行一个。

## 题 5.4 enumerate / zip 实战

读入两行等长的整数序列 `a`、`b`。  
输出所有满足 `a[i] < b[i]` 的下标 `i`（从 0 开始），空格分隔；若无则输出 `none`。

要求：使用 `enumerate` + `zip` 的写法。

```
输入：
1 5 3 8
2 4 7 8
输出：
0 2
```

## 题 5.5 字符频率 TopK

读入一个字符串 `s` 与整数 `k`（第二行）。  
输出出现次数最多的 `k` 个字符（次数降序；次数相同按字符升序）。  
格式：每行 `字符 次数`。

```
输入：
abracadabra
3
输出：
a 5
b 2
r 2
```

## 题 5.6 any / all（选做）

读入一行整数：

- 若全部为正，输出 `all_positive`  
- 否则若至少一个为正，输出 `some_positive`

## 推荐顺序

**若距离考试只剩约 11 天：** 直接打开并执行 `03-十一天急救日历.md`，不要从零按 6～8 周计划走。

时间充裕时：

1. 先读 `00-学习计划总览.md`  
2. 按 `modules/01` → `07` 做题  
3. 再进入 `02-科目一冲刺计划.md`  
4. 在 `progress.md` 勾选完成情况  

## 做题约定

- **手敲**，少复制；每题至少自测 3 组数据  
- 做完可把代码放到 `solutions/` 下，文件名如 `m01_q03.py`  
- 卡超过 30～40 分钟：先看思路提示（若有），再合上自己重写一遍

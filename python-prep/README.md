## 推荐顺序

1. 先读 `00-学习计划总览.md`，定每天可投入时间  
2. 按 `modules/01` → `07` 做题，同步对照 `01-唤醒Python手感.md`  
3. 手感回来后，进入 `02-科目一冲刺计划.md`  
4. 在 `progress.md` 勾选完成情况  

## 做题约定

- **手敲**，少复制；每题至少自测 3 组数据  
- 做完可把代码放到 `solutions/` 下，文件名如 `m01_q03.py`  
- 卡超过 30～40 分钟：先看思路提示（若有），再合上自己重写一遍

# 学习计划总览

## 你的现状（按对话整理）

- 华为可信专业级：科目二～四已过，**只差科目一**
- 多年不写代码 → 先唤醒手感，再刷算法
- 考试语言：**Python**

## 科目一目标状态

- 2 道中等：稳定全过或接近全过
- 1 道困难：能拿大部分用例分
- 限时、手敲、少依赖补全时也不慌

## 总周期建议

| 每天可投入 | 建议总周期 |
|------------|------------|
| 1.5～2 小时 | 6～8 周 |
| < 1 小时 | 8～10 周 |
| ≥ 2.5 小时 | 可压到约 5～6 周 |

### 三阶段

```
阶段 A（1～1.5 周）  唤醒 Python 手感     → 见 01-唤醒Python手感.md
阶段 B（1.5～2 周）  数据结构入门刷题     → modules 02～05 + 简单算法
阶段 C（3～4 周）    科目一冲刺 + 模考   → 见 02-科目一冲刺计划.md
```

**原则：科目一始终占主要精力；理论科目已过，不要再摊。**

## 每日作息样例（在职）

| 时段 | 内容 |
|------|------|
| 前 40 分钟 | 写 1 道完整题（从易到中） |
| 中 30 分钟 | 对照题解后，合上重写一遍 |
| 后 20 分钟 | 默写 1 个模板（输入 / 二分 / BFS 等） |

> 1 题吃透 > 5 题糊弄。

## 考场策略（科目一）

1. 先扫 3 题，标易/中/难，先做最稳的两道中等  
2. 中等卡 25～30 分钟仍无清晰思路 → 换题  
3. 困难先保证正确性拿部分分，再谈最优  
4. 交题前自测：空、单元素、全相同、极大值、极端字符串  
5. 留最后 5～8 分钟扫 bug（下标、off-by-one、未初始化、忘 return）

## 模板本最少清单

考前能默写：

- [ ] 标准输入 / 多行输入拆分  
- [ ] 二分上下界骨架  
- [ ] 滑动窗口骨架  
- [ ] BFS / DFS / 回溯剪枝  
- [ ] 堆、并查集、拓扑  
- [ ] 常见 DP 壳子（背包、路径、LIS 思路）  

## 检查点

| 节点 | 通过标准 |
|------|----------|
| 阶段 A 结束 | 不查文档能写出「读入 → 处理 → 打印」完整程序 |
| 阶段 B 结束 | 简单～中等偏易题能独立 AC，列表/字典/搜索不陌生 |
| 冲刺中期 | 每周模考能稳定做完 2 道中等 |
| 考前 | 3～4 场全真模考复盘完毕，错题本只留仍会错的 |

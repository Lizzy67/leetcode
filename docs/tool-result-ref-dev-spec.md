# 工具结果引用机制 · 开发接入规范

> 状态：V1 草案（供工具接入方与运行时开发评审）  
> 配套阅读：`docs/tool-param-ref-mechanism.md`（顶层设计）、`docs/tool-param-ref-example.html`（端到端示例）、`docs/workmemory-ref-scheme.md`（早期方案）  
> 规范用语：**必须** / **禁止** 为强制项，**建议** 为推荐项，**可选** 为按需项。

---

## 1. 目的与读者

本规范定义工具返回结果在智能体运行时中的**存储、送模呈现与引用回填**规则，供以下角色使用：

| 角色 | 关注章节 |
|------|----------|
| 工具 / 业务接入方 | §2 适用场景、§4 呈现分类、§5 选型指引、§6 接入步骤、§7 策略配置 |
| 运行时（Runtime）开发 | §3 核心概念、§8 运行时行为、§9 失败与歧义 |
| 测试 | §10 验收清单 |

一句话总述：**工具返回默认入工作记忆并分配短结果标识（resultId）；运行时按呈现策略决定每个字段以原文、掩码占位或完全隐藏三种形态之一面向模型；模型在后续工具入参中一律输出 `${resultId.path}` 引用；运行时在工具执行前解析回填真值，解析失败短路。**

---

## 2. 适用场景

### 2.1 应当接入（命中任一即建议接入）

| 编号 | 场景 | 典型特征 |
|------|------|----------|
| S1 | 跨工具结果传递 | 上游返回 URI / ID / 大段文本，下游以同值为入参（先搜图再拼图再发布） |
| S2 | 指针型字段 | `fileUri`、`objectId`、ID 列表等：模型无需理解内容，只需转交 |
| S3 | 长值防抄错 | 值超过约 64 字符或含随机串（token、签名 URL），模型照抄易截断/改写 |
| S4 | 大结果省 Token | 返回体大，模型只需读摘要，不需读全量 |
| S5 | 结构不一致 | 上游输出结构 ≠ 下游入参结构，需执行前变换（配合 beforeHookPolicy） |
| S6 | 敏感 / 不宜送模字段 | 内部标识、调试信息、隐私字段，不希望进入模型上下文 |

### 2.2 不适用（不要为这些场景引入引用）

- 用户原话中的短字面量（相册名、数量、城市名）：模型**直接填写**；
- 单工具调用、无下游消费的结果字段；
- 模型需要**改写加工**后再输出给用户的内容（引用只做原值转交，不做改写）。

---

## 3. 核心概念

### 3.1 存储结构（工作记忆，会话作用域）

| 结构 | 内容 | 是否可进模型上下文 |
|------|------|--------------------|
| `resultDataList` | 工具返回的**业务主体**，引用解析的**主数据源**（优先查） | 是——具体以原文还是掩码形态呈现，由呈现策略决定 |
| `dataForTool` | 仅供运行时 / 执行层消费的**附加数据**（端侧打开用长 URI、内部句柄等），引用解析的次级数据源 | **否——任何形态都不进上下文** |
| `resultId ↔ toolCallId` 映射 | 对模短标识 ↔ 对内调用标识 | resultId 可见，toolCallId 不送模 |

- `resultId` **必须**由运行时统一生成（推荐 `hex8(hash(toolCallId))`），全链路唯一算法，**禁止**各子系统自行派生。
- 每条结果**必须**记录作用域（会话 / 租户 / 设备）与有效期（TTL）。

### 3.2 引用语法

```
${resultId.path}
```

- `resultId` 段仅含字母数字；首个 `.` 之后为字段路径（受限 jsonpath，禁函数、禁越界表达式）。
- 占位符**必须**作为完整参数值或值内完整片段出现，模型**禁止**改写其内部字符。

## 4. 送模呈现分类（规范核心）

工具返回中的每个字段，经呈现策略（`capturePolicy`）判定后，归入以下三类之一。

> 术语对照：早期文档中的 `maskPolicy` 即本规范 `capturePolicy` 的掩码子集；本规范统一用 `capturePolicy` 表述三类呈现的完整判定。

### A 类 · 可见呈现（VISIBLE）

| 项 | 规则 |
|----|------|
| 存储 | `resultDataList` |
| 送模形态 | **原文**进入模型上下文 |
| 下游传参 | 模型**仍必须输出引用**（看传分离）：读过 ≠ 可以抄 |
| 适用 | 模型必须阅读其内容才能推理、播报或决策的字段：`summary`、`aiDesc`、状态结论 |

> A 类是「看」与「传」分离的场景：值对模型可见，供其理解；但写入下游工具入参时仍写 `${rN.path}`，由运行时回填，杜绝长文抄写错误。

### B 类 · 掩码呈现（MASKED）

| 项 | 规则 |
|----|------|
| 存储 | `resultDataList`（真值只在工作记忆） |
| 送模形态 | 字段**出现**在上下文中，但值被替换为引用占位符本身（如 `"collageUri": "${r2.collageUri}"`） |
| 下游传参 | 模型照抄所见占位符（所见即所填） |
| 适用 | 模型需要**感知存在并决定传给谁**、但无需读内容的指针型字段：`fileUri`、`*Url`、ID 列表 |

> B 类让模型知道「有一个可引用的对象」，并把引用形态直接放在它眼前；模型的唯一正确动作是原样回传。

### C 类 · 隐藏（HIDDEN）

| 项 | 规则 |
|----|------|
| 存储 | `dataForTool` |
| 送模形态 | **完全不出现**在上下文中（连字段名和占位符都没有） |
| 下游传参 | 不经模型：由运行时 / 执行层按约定直接衔接；或由 Skill 文档化的固定路径引用 |
| 适用 | 模型全程无需感知的执行层数据：端侧打开用的内部 URI、调试信息、协议附加字段 |

> C 类与 B 类的分界：**模型是否需要参与「把它传给谁」的决策**。需要 → B（给占位符让它转交）；不需要 → C（运行时自动衔接，模型连存在都不知道）。

### 分类速查

| | A 可见 | B 掩码 | C 隐藏 |
|---|---|---|---|
| 进上下文 | 原文 | 占位符 | 否 |
| 存储位置 | resultDataList | resultDataList | dataForTool |
| 模型动作 | 读内容 + 传参写引用 | 照抄占位符 | 无感知 |
| 引用可解析 | 是 | 是 | 是（次级查找） |

## 5. 选型指引

对返回结构中的每个字段依次回答：

```
① 模型需要阅读该值的内容（推理/播报/决策）吗？
      是 → A 类（可见呈现；下游传参仍须引用）
      否 ↓
② 模型需要决定「这个值传给哪个下游工具」吗？
      是 → B 类（掩码呈现，占位符所见即所填）
      否 ↓
③ 仅运行时 / 执行层消费 → C 类（隐藏，入 dataForTool）
```

叠加规则：

- 命中 §2.1 S3（长值）且回答①为「是」：仍归 A 类，但**建议**同时产出短摘要字段供播报，长原文按需折叠；
- 命中 S6（敏感）：无论①②如何，**必须**至少 B 类；模型完全无需感知时**必须** C 类；
- 列表字段（如 `merged_id_list`）：默认 B 类；若下游入参结构不一致，叠加参数转换规则（§7.3）。

## 6. 工具接入步骤

接入方按以下顺序完成，全程**不修改工具实现与参数签名**：

1. **字段分类**：按 §5 对返回结构逐字段标注 A / B / C；
2. **配置 capturePolicy**：仅需声明与通用规则不同的例外（见 §7.2）；C 类字段若由工具直接产出，写入返回体的 `dataForTool` 区段；
3. **配置参数转换规则**（可选）：下游入参结构不一致时，为目标参数编写 JSONata 表达式（见 §7.3）;
4. **Schema 核对**：指针型入参**建议**在工具 schema 描述中注明「填写 `${resultId.path}` 引用」；
5. **Skill 约定**：确认所属技能已包含通用引用规则（引用照抄、可见仍引用、禁止编造真值），工具特有约定补入技能说明；
6. **按 §10 清单自测**。

## 7. 策略配置规范

策略仓三层结构，细粒度覆盖粗粒度：**参数级 > 工具级 > 通用**。

### 7.1 通用规则（全局兜底）

```json5
global.capturePolicy {
  mask: ["*Uri", "*Url", "*_id_list", "fileId", "objectId"]   // 命中字段名模式 → B 类
  // 未命中任何规则的字段默认 A 类（可见）
}
```

### 7.2 工具级规则（业务例外，覆盖通用）

```json5
searchPhotos.capturePolicy {
  visible: ["summary"]        // 显式 A 类（即使命中通用 mask 模式也放行）
}
createCollage.capturePolicy {
  visible: ["aiDesc"],
  hidden:  ["debugTrace"]     // 显式 C 类：剥离至 dataForTool，不进上下文
}
```

- 同一字段命中多条时按**最严格**生效：`hidden > mask > visible`；
- C 类字段的两个来源等价：工具返回体自带 `dataForTool` 区段，或 `capturePolicy.hidden` 由运行时从主体剥离。

### 7.3 参数转换规则（参数级，执行前变换）

引用求值**之后**、schema 校验与工具执行**之前**，按 JSONata 表达式变换（详见 `docs/tool-param-ref-mechanism.md` §场景 S6）：

```json5
createCollage.beforeHookPolicy {
  images: "$map($, function($v) {{ 'file_id': $string($v) }})"   // $ = 引用展开后的真值
}
```

约束：表达式**必须**来自策略配置（**禁止**模型生成）；禁用 `$eval`；求值超时与输出上限由运行时统一设定；失败走短路。

## 8. 运行时行为（规范性）

1. **写入**：工具成功返回 → 业务主体写 `resultDataList`，附加数据写 `dataForTool`，分配 `resultId` 并登记作用域与 TTL；
2. **送模**：按 capturePolicy 渲染送模视图（A 原文 / B 占位符 / C 剥离）；B 类占位符形态**必须**与引用语法一致（所见即所填）；
3. **解析**：拦截器在**所有**工具 invoke 前递归扫描参数，对每个 `${…}`：先查 `resultDataList`，未命中查 `dataForTool`；校验作用域与有效期；
4. **变换与校验**：命中参数转换规则则执行表达式；最终参数过 schema 校验；
5. **调用**：全部必要引用完成求值且参数合法，才向工具发出请求。

---

## 9. 失败与歧义处理

| 情形 | 行为 |
|------|------|
| 引用语法非法 / resultId 不存在 / 路径无效 | **短路**：不调用工具，返回结构化错误（错误类型 + 位置），**禁止**把 `${…}` 原文透传给工具 |
| 引用过期 / 作用域不匹配 | 同上，错误注明过期或越权，引导模型重新获取 |
| 转换失败 / 校验不过 | 同上，**禁止**透传未变换或半成品参数 |
| 解析出多个候选 | **禁止静默选一**：返回候选摘要（引用 + 人读标签，不含真值），或将合法引用动态写入该参数的 schema 枚举供模型 / 用户选择 |
| 图片等非引用形态裸值出现在引用约定参数位 | 短路拒绝（防编造 URI） |

---

## 10. 测试验收清单

- [ ] A 类字段：原文可见；下游传参为引用而非抄写原文；
- [ ] B 类字段：上下文中为占位符；模型回传占位符后工具收到真值；
- [ ] C 类字段：上下文中无该字段；执行层正常取得数据；
- [ ] 引用指向不存在的 resultId / 路径：工具未被调用，错误结构化返回；
- [ ] 引用过期（跨会话 / 超 TTL）：短路且提示过期；
- [ ] 参数转换：列表→对象数组正确；**单元素输入**输出仍为数组；空列表行为符合预期；
- [ ] 多候选歧义：未静默选取，候选摘要或枚举生效；
- [ ] 存量工具未配置任何策略：通用规则兜底生效，调用链路无回归。

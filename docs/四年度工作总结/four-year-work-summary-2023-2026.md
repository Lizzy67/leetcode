# 个人工作总结与规划（2023–2026）

近四年，本人担任小艺视觉 / 多模 CV 解决方案 SE，工作主线从视觉原子能力与 HiTouch、HiVision 体验打磨，演进到 OnApp 多模中控与语音视觉融合交互，再深化到看世界、看屏幕、图库与相机智能化，以及 Agent Skill 化统一架构；并持续沉淀工具大结果引用传参、应用分身、快慢系统协同等可复用底座，支撑商用落地与后续架构演进。

一、四年工作贡献

1. 2023 年：主导多模视觉发布会亮点特性方案设计并推动商用。包括 On App 小艺 5.0（所见即可问）、AIGC 贺卡与 LEM 头像生成、识图说与视觉意图气泡、智慧搜图与智慧抠图/消除等。负责单框架视觉业务与 HiAiEngine 迁移，推动 OCR、人脸检测聚类、美学引擎等能力下沉 AI 子系统，构建文档扫描、卡证识别等场景化控件。负责 HiTouch、HiVision 多 OBP 需求打磨，助力小艺 NSS 整体提升近 10 个点。同步负责对话大模型 AIGC 及小艺帮写等能力，完成 Agent 相关技术储备。负责北京地域合作方相关事项，完成立项、结项与人员调配。

2. 2024 年：主导 HDC 关键特性 OnApp 圈选推荐与面屏操作方案设计，并输出核心专利（基于屏幕圈选的智慧交互）；支持指关节、HiTouch 与语音三大入口融合，实现视觉与语音真正融合交互。统一多模架构，实现 chips 1 秒级推送，图片知识检索问答准确率达 97%，卡证、订单等多模信息抽取准召达 95%（相对单模基线 80%～85% 显著提升）。小艺圈选在 CePi 卖点秀竞争力排名第 9、营销价值排名第 6；上市后 AI Bar 内部满意度最高，视觉搜索体验行业 TOP2。推进 OnApp 2.0 链接 Agent Kit 与 UserGraph，完成教育 Agent 方案并支撑约两周原型上线，启动看世界全模态连续对话。作为技术合作经理，完成 10+ 立项合规看护、江苏科技课题 11 项申报、人才 funding 筛选 33 名优秀青年教师，组织哈工大创新实验室年度研讨并获所团队奖。作为合作方项目华为 PM，项目结项获 S 级评价，完成 3 年期任务交接。

3. 2025 年：作为视觉产品 SE，负责领域需求评估与统一架构方案分析。针对图库编辑生成、主题风格化、编创等场景设计统一链路与异步分发优化，解决 DMQ 同步阻塞问题，推进云侧多模架构统一；指导完成小艺修图、编创、照相馆等智能体方案设计。负责小艺看世界与看屏幕重点特性：完成眼镜拍照问答、实时视频流及解题/翻译等接入，打通看屏幕端到端流程，支持信息框出与圈选、手势指代。负责相机 Copilot 操控类需求，支持语音接管式协作、伴随态灵感推荐与姿势检测收藏直达等场景。

4. 2026 年：主责鸿蒙 7.0 图库、相机、看世界等多模智能化方案设计与落地。围绕修图、编创、相册整理、搜索等场景，构建 inapp / onapp / 主对话多入口体验，基于小艺 Skill 化沉淀统一技术架构并支撑商用；设计小艺应用分身·图库首场景接入架构，支撑沉浸式交互；在 543 能干专项中沉淀工具大结果引用传参通用方案并输出专利，持续攻关时延、鉴权、状态互通等关键问题。上半年完成相机 6.1 小艺慧拍与 7.0 灵感智拍（相机 SA 经 AgentKit 对接灵感智拍 workflow）、图库分身快慢系统与修图美学 subagent、看世界 2.0 导盲（接入 AREngine，超短时延避障）及支架小车情感化交互等方案设计。鸿蒙 7.1 相机小艺价值需求因后续变动，目前仍在讨论推进中。

二、对他人成功的贡献

四年来坚持每周辅导 OD 同事董闯，指导其沟通呈现与方案分析能力，助力其主导 VisionKit 场景化控件、单框架迁移及修图、编创、照相馆等智能体方案，逐步具备独当一面的视觉 SE 潜力。曾辅助同事完成 PDF 问答可行性与风险上报，配合 Prompt 评审每月 500～700 条用例。通过持续澄清架构边界与沉淀通用方案，为团队提供更清晰的技术方向与实施路径。

三、下一阶段努力目标

1. 闭环 Skill 化、应用分身与工具引用传参等底座能力在图库、相机、看世界等场景的商用落地与体验打磨。
2. 跟进 7.1 及相关需求澄清，收敛相机智能化等方案并支撑版本交付。
3. 加强架构抽象与方法论沉淀，主动优化跨模块边界，做好竞品洞察与方案归档分享，以更高质量的系统设计支撑部门产品竞争力与团队协作效率。

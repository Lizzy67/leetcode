# 四年度工作总结（2023–2026）

> 角色定位：小艺视觉 / 多模 CV 解决方案 SE  
> 覆盖周期：2023 上半年 → 2026 上半年（含鸿蒙 6.1 / 7.0 / 7.1 价值需求）

## 一、四年主线（一句话）

从 **HiTouch / HiVision 体验打磨与 VisionKit 原子能力下沉**，演进到 **OnApp 多模交互与语音视觉融合**，再演进到 **看世界 / 看屏幕 / 图库·相机多模智能化与 Agent Skill 化统一架构**，并持续沉淀 **工具大结果引用传参、应用分身、快慢系统协同** 等可复用底座，支撑商用落地与后续架构演进。

| 阶段 | 时间 | 关键词 | 代表性量化结果 |
|------|------|--------|----------------|
| 视觉能力与体验底座 | 2023 | 搜图抠图、识图说、AIGC 贺卡、VisionKit、HiTouch/HiVision | 助力小艺 NSS 整体提升近 **10** 个点；多模卖点商用上线 |
| 多模中控与融合交互 | 2024 | OnApp 圈选、chips、多模抽取、教育 Agent、技术合作 | chips **1 秒级**推送；知识问答准确率 **97%**；信息抽取准召 **95%**；CePi 卖点秀竞争力 **第9** / 营销价值 **第6** |
| 视觉重点特性深化 | 2025 | CV 生成架构统一、看世界/看屏幕、相机 Copilot、智能体设计 | 解决 DMQ 同步阻塞；眼镜拍照对话 / 实时视频流；辅导 OD 独立承担视觉 SE 工作 |
| Agent 化与场景纵深 | 2026 H1 + 7.0/7.1 | 图库/相机/看世界 Skill 化、分身、灵感智拍、导盲&具身 | 统一 inapp/onapp/主对话多入口；相机 SA↔AgentKit 灵感智拍 workflow；导盲超短时延避障 |

## 二、分年度量化成果

### 2023：视觉卖点商用 + 原生智能底座 + 大模型 AIGC

#### 关键个人贡献（量化）

1. **发布会 / HDC 卖点方案设计并商用**
   - **On App 小艺 5.0**：所见即可问，屏幕元素/图文实体问答与语音任务分发。
   - **AIGC 贺卡 & LEM 头像生成**：语音生成风格化图片 + 大模型祝福语；设计异步并发拥塞排队机制保障连续性。
   - **识图说 & 视觉意图气泡**：识文/识物/表格提取/试卷还原/图片翻译/文档扫描等落地语音场景，支持实时意图气泡。
   - **智慧搜图、智慧抠图/消除**：基于 CLIP 自然语义搜图；主体/万物分割 + 诺亚悟空算法支持智能抠图与平滑消除（辅导 OD 董闯完成方案）。
   - **评价对齐**：多模气泡、AI 贺卡、LEM 头像、图片拖拽与擦除等卖点特性商用上线。

2. **原生智能 / VisionKit / HiAiEngine**
   - 视觉原子能力下沉 AI 子系统：OCR、人脸检测聚类、美学引擎、单主体检测、视频语义等对外开放。
   - 构建文档扫描、活体检测、卡证识别等场景化控件；完成 HarmonyOS SDK AI-visionKit、CoreVision、CoreNLU 需求分析与可行性设计。
   - HiTouch / HiVision 多 OBP：吱口令、本地码分发、版面升级、超级中转站等；**评价对齐：助力小艺 NSS 整体提升近 10 个点**。

3. **对话大模型 AIGC**
   - 诗歌/作文/贺词/邀请函等文案能力；对接小艺输入法「帮写」、浏览器新闻摘要审核。
   - 通用 QA / 闲聊 QA 迁移；完成 XAgent 环境搭建与 LangChain 平台化分析，储备 Agent 能力。

4. **合作方项目管理**
   - 立项 AI 引擎开发项目 2/3 期与小艺业务开发-北京项目；完成 4 期结项与在离岸拆分；配合组织人员调配。

#### 对他人成功的贡献

- 每周辅导 OD 董闯（方案分析 + DEMO 验证）；辅助槐昱完成 PDF 问答可行性与风险上报；配合 Prompt owner 王宸昊每月评审 **500–700** 条 prompt 用例。

### 2024：OnApp 多模中控商业化 + 教育 Agent + 技术合作经理

#### 关键个人贡献（量化）

1. **HDC 关键特性：OnApp 圈选推荐与面屏操作（核心专利）**
   - 三大入口融合：指关节圈选 + HiTouch 双指按压圈选 + 语音命中视觉。
   - 统一多模架构：语音对话 / chips 执行 / 发图·拖拽对话；多模态大模型图文场景识别。
   - **量化结果：**
     - chips **1 秒级**推送；
     - 图片知识检索问答准确率 **97%**；
     - 卡证/订单等多模信息抽取准召 **95%**（相对单模基线 **80–85%** 显著提升）；
     - 二级唤醒降低误闯、节约云侧资源；多进程并行 + 端云优化显著降低截图上传时延；
     - **CePi 第二轮卖点秀：竞争力第 9、营销价值第 6**；
     - 上市后 AI Bar（屏幕问答、拖拽等）**内部满意度最高**；视觉搜索体验 **行业 TOP2**；
     - 输出核心专利：**基于屏幕圈选的智慧交互**。
   - 评价对齐：多模分发准确率 **90+**，为端到端多模中控打基础。

2. **OnApp 1.0→2.0 演进**
   - 1.0：切换多模态大模型中控，支持 caption 图生文，覆盖小红书/评论/朋友圈等创意文案。
   - 2.0：链接 Agent Kit 与 UserGraph，伴随式交互 + 流光 AI Bar 一键拉起垂域 Agent。

3. **小艺教育 Agent**
   - 解题/批改：版面理解 → 原题检索 → 单/多模态数学快慢思考模型 → 知识点详解 + 追问对话。
   - **评价对齐：支撑约两周内完成原型快速开发上线。**

4. **小艺看世界（起步）**
   - 全模态音视频连续对话；菜单翻译&问答、博物馆知识问答、解题等；后续覆盖文档/百科/记忆等技能。

5. **VisionKit 出海与领域 SE 看护**
   - Kit 出海港澳、日本、丹麦、西班牙等地区；持续看护 HiVision & HiTouch 单框架与颗粒化特性。

6. **技术合作经理（量化）**
   - 全年技术合规宣传；**10+** 立项流程看护与合规管理；
   - 哈工大创新实验室第一期目标达成，并组织年度技术研讨（刘挺校长、秦兵主任等 **10+** 位老师同学出席）；
   - 江苏省科技厅规划课题申报 **11** 个项目（超级对齐、多模态、知识问答、训练推理加速、数据合成、语音/唤醒、Agent 等）；
   - 终端云服务全年 CT/PR 测试通过；
   - 人才 funding 2024 H1+H2 业务终审：筛选 **33** 名优秀青年教师；
   - 获 **2024 年度北京研究所-技术要素和人才培养所团队奖**。

7. **华为 PM（北京地域架构设计部合作方）**
   - 立项小艺业务开发-北京项目 1/2 期，1 期结项获 **S 级**评价；
   - 2022 年以来 PR 筛查：自检 **14** 个问题闭环，抽检 **7** 个问题上报他项闭环；
   - 7 月起交接，**3 年期 PM 任务圆满完成**。

#### 对他人成功的贡献

- 持续辅导董闯：主导 VisionKit 场景化三大控件、单框架迁移、OnApp/发图拖拽/春节贺卡/照相馆等方案，逐步具备独当一面视觉 SE 潜力。

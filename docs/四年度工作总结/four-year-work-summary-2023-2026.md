# 个人工作总结与规划（2023–2026）

近四年，本人作为小艺视觉 / 多模领域解决方案 SE，围绕屏幕多模交互、图库与相机智能化、看世界等方向，持续承担重点特性方案设计与架构看护，推动能力从单点卖点走向统一架构与商用闭环，并为下一阶段 Agent 化演进打基础。

工作贡献方面：2023 年主导智慧搜图与抠图、识图说与意图气泡、AIGC 贺卡等发布会卖点方案并推动商用，推进 VisionKit 等视觉能力下沉与场景化控件建设，打磨 HiTouch / HiVision 体验，助力小艺 NSS 提升近 10 个点。2024 年主导 HDC 关键特性 OnApp 圈选与面屏操作，打通指关节、HiTouch 与语音三大入口，实现视觉与语音融合交互，输出屏幕圈选智慧交互专利；实现 chips 秒级推送，图片知识问答准确率达 97%，卡证订单等多模信息抽取准召达 95%，CePi 卖点秀竞争力第 9、营销价值第 6，AI Bar 内部满意度居前，视觉搜索体验进入行业前列；同步完成教育 Agent 方案并支撑快速原型上线，启动看世界全模态连续对话，并完成技术合作与合作方项目管理等组织性工作。2025 年聚焦 CV 生成类统一架构与异步分发优化，解决 DMQ 同步阻塞并推进云侧多模架构统一；完成看世界、看屏幕端到端方案（含眼镜拍照问答、实时视频流、圈选指代等），以及相机 Copilot 语音接管与灵感推荐等能力设计，指导修图、编创、照相馆等智能体方案落地。2026 年主责鸿蒙 7.0 图库、相机、看世界等多模智能化：构建 inapp / onapp / 主对话多入口体验，基于 Skill 化沉淀统一技术架构并支撑商用；设计小艺应用分身·图库首场景接入架构；在能干专项中沉淀工具大结果引用传参通用方案并输出专利，持续攻关时延、鉴权与状态互通；完成相机慧拍 / 灵感智拍（对接 AgentKit workflow）、图库分身快慢系统协同，以及看世界导盲与具身交互等方案设计。鸿蒙 7.1 相机小艺价值需求因后续变动仍在讨论推进中。四年来坚持辅导同事成长，助力团队在视觉 SE 方向形成更清晰的方案承接能力。

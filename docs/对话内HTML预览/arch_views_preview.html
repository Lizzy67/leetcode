2. 鉴权口径（已定：不引入 AK/SK）

  • Agent → 预览服务：走现有服务间可信通道（内网/会话态等），不落 AK/SK。
  • WebView → 打开链接：只打开返回的短时 preview_url；密钥不进 WebView、不进 HTML。

一句话：不带 AK/SK；WebView 只拿短时 preview_url。

4. 静态目录资源有啥用？

就是一个页面拆成 index.html + css + js + 图片 多个文件时，预览服务按目录一起托管。一期单文件（CSS/JS 内联）不需要这个能力，完全可以以后再加。

6. 流式 B/C 是什么？

这是主 PPT 里另外两条「不经过预览服务、直接把 HTML 文本推到端上渲染」的备选：

  • B：模型边生成边往端上推，端边收边刷新。
  • C：先流式粗看，完成后再定稿替换。

你们已定主路径是「预览服务出链接」，所以 B/C 先不进这张架构图。

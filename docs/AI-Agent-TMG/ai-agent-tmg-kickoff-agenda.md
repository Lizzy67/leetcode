## 建议会前材料（主任准备 1 页）

1. 章程正文（已发）  
2. 建议成员名单（含角色）  
3. 首批准入清单草案（见章程第 7 节）  
4. 标准建设候选（任选推进）：  
   - Tool / Skill 版本与兼容规范  
   - 智能体领域架构边界与分层说明（系统 vs 应用）  
   - 工具调用异常 / 不存在能力处理基线  
   - 公共能力口径（结果引用传参、分身接入等）

Workmemory 引用方案 · 一页纸

对齐 TaiChu #2520 / Lizzy67 定稿要点
语法 ${resultId.jsonpath} · resultId = UUID

1. 背景

  • 精确值（URI / fileId / 大段 JSON）经模型多次搬运易抄错。
  • 模型只需感知短引用；执行前由 Runtime/DM 回填真值。
  • 跨端（PC→service）只传 summary 实际用到的引用（见 #2520 bundle）。

2. 定稿原则

  • resultId 统一 UUID（opaque 128-bit），不再用 toolCallId 截断 hash。
  • toolCallId 仅作来源追踪 / 内部幂等，不进公开引用身份。
  • Mask policy 绑定 Runtime：一套 Runtime ↔ 一套 policy。
  • 引用在快/慢系统内闭环；边界外暂不传，出边界再恢复（后续）。

3. Mask / Policy

  • 指针字段默认 mask（fileUri / fileId / objectId / *Url…）。
  • 工具可覆盖；优先级：工具配置 > Runtime 默认。
  • 值不可见 → policy 替换为 ${uuid.path}。
  • 值可见 → 结果根目录落工作区；按 Prompt/Skill 要求模型输出引用。

4. 慢系统 Loop（DM ↔ 太初）

① MCP 返回DM 调工具拿结果
② 缓存 WMDM 写入 workmemory
③ 太初 mask按 Runtime policy 加 mask
④ 模型推理看到短引用 / 可见摘要
⑤ 太初还原出参引用 → 真值
⑥ DM 执行无引用则无需再还原

场景① 值不可见

  • Policy mask；模型只感知变量。
  • 需持久化：sessionStore，挂在 ToolResult message 的 extendData。
  • 与 #2520 增强一致：extendData.toolResultReferences。
${019f…a12.fileUri} → 执行前还原；原值不进日志/UI/Provider

场景② 值可见

  • 例：先生成 Java，再把其中一份转成 Python。
  • 结果根目录缓存到工作区；模型按 Prompt/Skill 输出 resultId.jsonpath。
  • 不持久化：workmemory 仅内存临时保存。
可见代码摘要 → 入参仍用 ${uuid.text}

5. 入参替换（递归）

  • 工具入参 JSON 递归遍历所有字段。
  • 区分：整体变量引用（整值 = ${...}）与 值内引用（字符串内嵌 token）。
  • 命中后替换；未命中 / 冲突 fail closed。
  • 查找：WM / Reference Map → jsonpath；跨 Runtime 不直接共享 ID。

说明：#2520 sink/summary 侧仍要求「完整 token 独占 string」；DM 入参侧按本条做递归/值内替换。

6. SubAgent 特殊规则

  • 输出阶段即对 URI 等加 mask。
  • 特殊工具 / hook：从自然语言中抽出 ${...}，随 memoryList 返回。
  • 输入 mask 不还原；输出 mask 也不还原。
  • 需裁剪 memoryList{引用名:变量值} 交回父侧。

7. 与 #2520 / 跨端的衔接（必读）

  • PC CapturePolicy → Runtime 捕获 → 模型见 local ref → summary 保留完整 ref → referenceBundle 按需导出（不改 Relay 协议，放 extendData / private payload）。
  • service 侧导入并 remap 为 service-local UUID ref；主 Agent 只见本地引用。
  • 快系统上下文 UAT 当前无指代；引用不在快慢之间传；出边界恢复属后续能力。
  • 融合回复里的指代（如「下面是脑图 ${XXXX.fileLink}」）由 Runtime 投影/交付约束保证完整 token，禁止拼接截断。

8. SystemPrompt 建议文案（可直接嵌入）

作用范围：工具入参「照抄上一步结果」；用户原话 / 可独立确定的字面量仍直接填。
# 工具结果引用约定

当某个工具参数的取值来自上一步某条工具结果中的字段时，不要复述、改写或猜测该值，请输出引用占位符，由系统在执行前回填真实值。

## 写法
`${<resultId>.<字段路径>}`

- `<resultId>`：上下文中对应工具结果的 UUID（字母数字与连字符）。必须照抄上下文，禁止编造。
- `<字段路径>`：该结果内的字段路径，支持点号嵌套，例如 `entityId`、`data.fileUri`。
- 作为完整参数值时：整个参数必须等于占位符本身（不要省略 `$`/`{`/`}`，不要前后拼接）。
- 若参数说明允许值内引用：可在字符串中嵌入完整 `${...}` token，仍禁止改写 UUID 或路径。

## 何时必须用引用
- 参数说明要求引用，或取值明确来自已有工具结果字段；
- 尤其当该值较长（建议：超过约 12 个 token，如 URI、fileId、大段文本）时，禁止照抄原文。

## 何时仍填字面值
- 取值来自用户原话，或可独立确定的短信息（如相册名、数量、开关等），且并非某一工具结果字段的拷贝。

具体该引用哪个字段，以各工具/方法的参数说明为准。
UUID resultId · Runtime 绑定 mask policy · 不可见值进 extendData / 可见值仅内存 · 入参递归替换 · SubAgent 出入 mask 不还原、交 memoryList · 跨端走 #2520 referenceBundle。

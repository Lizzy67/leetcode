Workmemory 引用方案 · 一页纸

语法 ${resultId.jsonpath}
resultId = UUID.randomUUID().toString().substring(0, 8)

1. 背景

  • 精确值（URI / fileId / 大段文本）经模型多次搬运易抄错。
  • 模型输出非自然语言长值无意义且时延长。

场景① 值不可见 = 加 mask

  • 进模型前替换为 ${a1b2c3d4.fileUri}。
  • 模型只感知变量名，不看真值。
  • 精确值留在 Runtime 缓存，执行时还原。
典型：fileUri、fileId、长 URL

场景② 值可见 = 原样进模型

  • 原文原样输入给模型（供推理）。
  • 输出时仍按 SystemPrompt / Skill 只输出引用。
  • 由 Runtime 替换为真实值后再调下游工具。
例：先生成 Java 代码（可见）→ 再转 Python，入参用 ${e5f6a7b8.text}

2. 定稿原则

  • resultId：统一 UUID.randomUUID().toString().substring(0, 8)（取 32 位 UUID 字符串前 8 位）。
  • 引用场景分为 值可见 / 值不可见 两种（见上）。
  • 进模型前：按默认/工具 policy（+ 正则）加 mask；Runtime 缓存 resultDataList。
  • Skill / SystemPrompt：约束模型输出引用；加 mask 后只能出引用，禁止照抄原值。
  • Runtime 解析：递归遍历入参，整体/值内引用 → 查缓存还原真值；未命中 fail closed。

3. Runtime

  • Mask policy 绑定 Runtime：一套 Runtime ↔ 一套 policy。
  • 默认 policy：拦截 fileUri / fileId / objectId / *Url 等字段。
  • 工具 policy：可标明额外拦截变量；优先级：工具 > 默认。
  • 支持配置 正则：某类变量值命中则加 mask。
  • 缓存工具返回的 resultDataList，执行前解析引用为真值。

4. 逻辑架构

① 工具 A 返回产出精确结果
② Runtime 改写mask 并存 workmemory
③ 模型推理输出引用变量
④ Runtime 改回引用 → 真值
⑤ 调用工具 B使用真实入参执行

5. 快慢系统结合后

① MCP 返回DM 调工具拿结果
② 缓存 WM写入 workmemory / resultDataList
③ 太初 mask按默认/工具 policy（+正则）
④ 模型推理不可见见引用；可见见原文
⑤ 太初还原出参引用 → 真值
⑥ DM 执行无引用则无需再还原

6. resultId 与入参替换

  • 生成算法统一：UUID.randomUUID().toString().substring(0, 8)。
  • 工具入参 JSON 递归遍历：整体变量引用 + 值内引用，再替换。
  • 查找：Runtime 缓存的 resultDataList（及必要的 dataForTool）。

7. SubAgent 特殊规则

  • 输出阶段对 URI 等加 mask。
  • hook 抽出自然语言中的 ${...}，随 memoryList 返回。
  • 输入 / 输出 mask 均不还原；裁 memoryList{名:值} 交回。

8. SystemPrompt 建议文案（可直接嵌入）

作用范围：工具入参「照抄上一步结果」；用户原话 / 可独立确定的字面量仍直接填。
# 工具结果引用约定

当某个工具参数的取值来自上一步某条工具结果中的字段时，不要复述、改写或猜测该值，请输出引用占位符，由系统在执行前回填真实值。

## 写法
`${<resultId>.<字段路径>}`

- `<resultId>`：上下文中对应工具结果的 8 位 ID（UUID 前 8 位）。必须照抄上下文，禁止编造。
- `<字段路径>`：该结果内的字段路径，支持点号嵌套，例如 `entityId`、`data.fileUri`。
- 作为完整参数值时：整个参数必须等于占位符本身（不要省略 `$`/`{`/`}`，不要前后拼接）。

## 何时必须用引用
- 参数说明要求引用，或取值明确来自已有工具结果字段；
- 字段已被 mask，或值较长（建议超过约 12 个 token）时，禁止照抄原文。

## 何时仍填字面值
- 取值来自用户原话，或可独立确定的短信息（如相册名、数量、开关等），且并非某一工具结果字段的拷贝。

具体该引用哪个字段，以各工具/方法的参数说明为准。
resultId = UUID 前 8 位 · 不可见加 mask / 可见原样进模但只出引用 · 工具A → Runtime改写入库 → 模型出引用 → Runtime改回 → 工具B。

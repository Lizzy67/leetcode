需要你确认的架构问题

  1. 预览服务形态：全新独立服务，还是已有网关/BFF 上的一个模块？是否可以暂时用「对象存储签名 URL + 轻网关」代替完整站点？
  2. preview_url 鉴权：短时签名匿名可开，还是必须带登录态？WebView 能否方便带 Cookie/Token？
  3. 与云空间关系：publish 时是「读云空间 file_id 再托管」，还是 Agent 直接把 HTML 帖到预览服务、云空间只做备份？
  4. 多文件：一期是否只保证单文件 HTML（内联 CSS/JS）？还是预览服务一开始就要支持目录级静态资源？
  5. 端形态：运行视图是否只画 App WebView，还是 Web 控制台 iframe 也要并列？
  6. 流式 B/C：架构图要不要单独画一条旁路，还是本期明确不进主架构？
